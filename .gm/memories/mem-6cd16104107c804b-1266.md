streaming-gltf WebGPU path REMOVED (commit bf3917b, master, pushed). The opt-in WebGPU renderer added in d2c92d2 was measured ~2x SLOWER than WebGL (36 vs 73-144 fps @ scale) because our hand-tuned WebGL GLSL onBeforeCompile optimizations (per-vertex gamma, GPU per-instance frustum cull) don't run under WebGPU (it used three's default shaders). Per user 'get rid of webgpu cause its slower', reverted stress.js to the plain synchronous WebGLRenderer (removed createRenderer factory, ?backend=webgpu, dynamic three/webgpu import, window.__backend), removed three/webgpu+three/tsl importmap entries, deleted webgpu-probe.{html,mjs} + webgpu-stress-check.mjs. WebGL is again the SOLE renderer.
