## Resolved mutable: webgpu-dual-backend-constraint

claude-code-guide survey + threejs r0.170 docs: NO. three/webgpu is a SEPARATE build (build/three.webgpu.min.js). Node materials (TSL) do NOT run on THREE.WebGLRenderer in r0.170. onBeforeCompile GLSL patching does NOT run on WebGPURenderer. Therefore a dual-backend renderer needs renderer-specific shader code: GLSL+onBeforeCompile for WebGLRenderer, TSL node materials for WebGPURenderer. WebGPURenderer has its own WebGL2 fallback backend but our existing GLSL patches won't execute on it. renderer.info.calls/triangles is unreliable under WebGPURenderer (use timestamp queries or skip). render() is sync after async init(); use await renderer.init() or setAnimationLoop.
